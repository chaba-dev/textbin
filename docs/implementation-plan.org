** DONE Implement CLI login flow
The CLI stores non-secret profiles in the platform configuration directory and
stores bearer tokens in the native OS credential store. =TEXTBIN_URL= and
=TEXTBIN_TOKEN= remain non-persistent overrides for CI and headless systems.

Password-enabled accounts bootstrap a fresh named API token through
=POST /api/v1/auth/tokens=. Passwordless accounts can import a settings-generated
token through the hidden =--with-token= prompt. Tokens are verified through
=GET /api/v1/me= before use.
